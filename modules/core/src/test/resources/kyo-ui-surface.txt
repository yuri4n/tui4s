# TASTy of the jar with tasty-query and compares it with this list. A new, removed or changed line fails
# the test: read the kyo-ui change, update the runner, then update this list.
# Format: kind<TAB>name<TAB>detail. Lines that start with # are comments.
# ast.type: kind, visibility and parents of a class, trait or object of kyo.UI.Ast (a class and its
#   companion object are one line). enum.case: a case of kyo.Style.Prop with its fields.
# ast.fields: the constructor fields of UI.Ast.Reactive and UI.Ast.Foreach (the region nodes that Mount and
#   Runner match on). bound.case: a case of UI.Bound with its fields (Mount.boundRef matches on Bound.Ref).
#   signal.method: the two kyo.Signal methods of the watcher loop, from the kyo-core jar (K29).
# claude 2026-10-12: created (the reader KyoUiSurface wrote this list from kyo-ui 1.0.0-RC7); changed: the
#   C2 part (ast.fields, bound.case, signal.method: the last 6 lines)
# C3 part: attrs.field: a field of UI.Ast.Attrs that Dispatch (or the focus order of Layout) reads, with its type.
#   ui.member: a member of an element that Dispatch reads (a field, or a def with no parameter list), with its
#   visibility and type. event.fields: the fields of KeyboardEvent, MouseEvent, Modifiers. keyboard.case: a case of
#   UI.Keyboard. pin: K2, Foreach.applyTyped is still private (Mount casts a Foreach). rule: the shape hash of a rule
#   method of kyo.internal.ReactiveUI that Dispatch or Mount copies; js: the hash of a rule fragment of the client JS
