# Sources

Page references such as "(PFP p. 133)" are **PDF page numbers** of the files in
the user's ebook library (`~/Library/Mobile Documents/com~apple~CloudDocs/Resources/`),
not printed page numbers. *Effect Oriented Programming* is an EPUB, so it is
cited by section (§ 4.7).

| Short name | Book | Library file | Printed page |
|---|---|---|---|

Other sources:

- **The Scala Compendium** (the user's project): <https://thescalacomp.dev>,
  repository `yuri4n/the-scala-compendium` (`shared/utils/atlas.ts` for the
  catalogue, `shared/data/guides.json` for the guides). Use it for library
  equivalents and bridges between ecosystems.
- **`functional-design`** (`~/.claude/skills/functional-design/`): the
  language-agnostic design principles (Granin, Wlaschin, Ghosh, Crichton,
  Normand, Parsons, Hughes, Bird & Gibbons, Okasaki, Stone). Its
  `references/sources.md` explains how to read an original chapter (download
  from iCloud, extract text with `scripts/pdf2txt.swift`).

Other Scala books in the library that can help with depth (not summarized
here): *Functional Programming in Scala* 2nd ed. (Pilquist, Chiusano,
Bjarnason, 2023), *Scala with Cats* (Welsh, Gurnell), *Essential Effects*
(Rosien, Cats Effect), *Functional Stream Processing in Scala* (Ali, fs2),
*Zionomicon* (De Goes, Fraser, Khajavi, ZIO), *Programming in Scala* 5th ed.
(Odersky, Spoon, Venners).

Dated items in PFP and FEDA are listed in SKILL.md under "Dated advice".
