```sh
sbt 'set core / Test / javaOptions += "-Dtui4s.stress=30"' 'core/testOnly tui4s.stress.PerfProbe'
```

This probe measures the pure layout and paint of one frame, with no runner and no terminal. It prints the median and the 90th percentile of each step, in ms, for a dashboard, a list of 2,000 rows and a log.

## bench/

The `bench/` directory is planned (it is not in the repository yet). It will compare the same apps in tui4s and in terminal UI libraries of other languages, with its own sbt build and its own CI job. The headline will not be speed. It will be:

- **Compactness**: the size of the code of the same app.
- **Expressiveness**: what each library can say directly.
- **Correctness**: the same behaviour in each implementation.
- **Resource management**: how each library releases the terminal and its other resources.

Performance will be on a page of its own, from a bounded cloud machine that stops by itself, with the machine and the method.
