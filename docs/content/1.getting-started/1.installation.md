## Requirements

- **JDK 25.** Kyo 1.0.0-RC7 needs JDK 25 to compile and to run.
- **Scala 3.9.0** or later.
- A terminal that supports ANSI escape codes. An IDE run console often does not support raw mode, so run your app in a real terminal.

## Add the dependency

Pick **one** module. Each module is a separate artifact with its own version.

| Module | Use it when your app uses |
| --- | --- |
| `tui4s-core` | Kyo |
| `tui4s-zio` | ZIO 2 |
| `tui4s-cats` | Cats Effect 3 |

::code-group
```scala [build.sbt]
libraryDependencies += "io.github.yuri4n" %% "tui4s-core" % "<version>"
```

```scala [project.scala]
//> using dep io.github.yuri4n::tui4s-core:<version>
```
::

::tip
`tui4s-zio` and `tui4s-cats` depend on `tui4s-core`, so you add only one dependency.
::

## Set up the JVM

### To compile

Kyo uses inline methods. A long for-comprehension can overflow the default stack of the compiler. Give the compiler a bigger stack:

::code-group
```text [.jvmopts]
-Xss16m
```

```bash [scala-cli]
export JDK_JAVA_OPTIONS=-Xss16m
```
::

### To run

The terminal backend loads a native library, and Kyo and Scala use `sun.misc.Unsafe`. Without these two flags, JDK 25 prints warnings over your UI:

```scala [build.sbt]
run / fork := true
run / connectInput := true
outputStrategy := Some(StdoutOutput)
run / javaOptions ++= Seq(
  "--enable-native-access=ALL-UNNAMED",
  "--sun-misc-unsafe-memory-access=allow",
)
```

::note
With sbt, `run / fork` and `run / connectInput` give the app the real terminal.
::
