Do not report a security problem in a public issue: [SECURITY.md](https://github.com/yuri4n/tui4s/blob/main/SECURITY.md) tells how to send a private report. The assistant example keeps API keys (in environment variables, in a file with mode 0600, or in the `localStorage` of the browser), and [ADR 0010](/decisions/0010-the-flagship-assistant-as-blueprint) and [ADR 0011](/decisions/0011-web-target-standalone-scalajs-and-one-theme) give its rules for them.
